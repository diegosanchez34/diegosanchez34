## Proyectos destacados

- **Plataforma de trazabilidad Green Trace:** Evolución y desarrollo de un sistema web integral para la trazabilidad industrial. El proyecto inició como una solución para registrar y seguir el uso de indumentaria mediante códigos de barra en lavanderías, escalando hasta convertirse en una plataforma técnica robusta enfocada en la industria salmonera.
- **Sistema Automatizado de Gestión Documental:** Liderazgo en el diseño, implementación y despliegue de un sistema web integral para gestionar documentación interna en empresas de servicios industriales, facilitando la operatividad y el control de activos digitales.
- **Sitios web corporativos y plataformas E-commerce:** Amplia experiencia en el desarrollo, mantenimiento y administración de tiendas online y páginas institucionales. Esto incluye la creación de sistemas desde cero, así como la gestión y migración de catálogos de alto volumen para diversos rubros comerciales.
